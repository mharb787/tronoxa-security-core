# Security Policy

This repository exists for review of the published security core. Do not include wallet secrets, recovery phrases, private keys, credentials, or personal data in an issue, pull request, log, or test.

For a vulnerability that could put users or funds at risk, report it privately to the repository owner through GitHub rather than opening a public issue. Include only synthetic reproduction data.

The published snapshot excludes the application UI, backend, provider integrations, deployment configuration, and business logic. A finding in an excluded component cannot be evaluated from this repository alone.
