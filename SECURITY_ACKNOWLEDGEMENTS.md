# Security Acknowledgements

TRONOXA thanks security researchers who report vulnerabilities responsibly and help protect wallet users.

No public acknowledgements are listed yet. A researcher will be added only with their explicit consent, after the issue is remediated and coordinated disclosure is safe. TRONOXA will not publish recovery phrases, private keys, PINs, OTPs, personal data or other sensitive report material.

To report a vulnerability, follow [SECURITY.md](SECURITY.md).
